## 1. 软件概述

### 1.1 软件简介

LinguaLeap 英语自学助手软件（以下简称"本软件"）是一款基于 Web 技术开发的综合性英语自学工具。软件面向英语自学者，通过科学的记忆算法与多样化的学习形式，帮助用户高效完成单词记忆、短语跟读、听力训练等学习任务。

本软件采用 React + TypeScript 技术栈开发，内置 7 大分类单词词库（5,500+ 单词条目）与 2.7 万余条常用短句库，支持桌面端与移动端双模式使用，并支持 PWA 离线安装。软件基于 Web Speech 语音合成技术提供中英文标准发音，结合间隔重复算法（SuperMemo-2）智能安排复习计划，实现"听说读写记"一体化学习。

### 1.2 功能特点

（1）**科学的记忆算法**：内置 SuperMemo-2 间隔重复算法，根据用户答题情况自动计算单词复习时间，到期自动进入复习队列，提升记忆效率。

（2）**海量内置词库**：内置 7 大分类、5,500+ 单词条目，涵盖日常生活、人物相关、基础知识、居家物品及日常/旅行/工作沟通短句等场景；另内置 2.7 万余条常用短句，按难度自动分级。

（3）**丰富的学习形式**：提供单词浏览、短语跟读、智能选择测验、听力拼句、连连看游戏、听力训练等多种学习形式，寓教于乐。

（4）**智能语音合成**：基于浏览器原生 Web Speech API，支持中英文发音人选择、语速与音量调节、慢速逐词播放、跟读循环播放等。

（5）**个性化学习设置**：支持深色/浅色主题、字体大小调节、每日学习目标设置，所有设置与学习进度本地持久化保存。

（6）**学习数据统计**：自动统计连续打卡天数、已掌握单词数、累计学习时长、今日学习次数，并设有成就里程碑与学习建议功能。

（7）**跨端适配**：支持桌面 Web 与移动端模式一键切换，移动端提供底部导航栏，支持 PWA 安装至桌面/手机主屏幕。

### 1.3 运行环境

本软件为 Web 应用，运行于现代浏览器环境。推荐使用以下浏览器的最新版本：

- Google Chrome 80 及以上版本
- Microsoft Edge 80 及以上版本
- Safari 14 及以上版本
- Firefox 75 及以上版本

说明：本软件的语音合成功能基于浏览器 Web Speech API，发音质量与可选发音人数量取决于操作系统及浏览器自带语音库（如 Windows 系统自带 Microsoft 语音、Chrome 浏览器提供 Google 在线语音等）。

## 2. 软件安装与启动

### 2.1 环境要求

- Node.js 18.0 及以上版本（用于构建与本地部署）
- npm 包管理器
- 支持 HTML5 与现代 JavaScript 的浏览器

### 2.2 安装步骤

（1）将软件源码包解压至本地目录，确认目录中包含 `package.json`、`App.tsx`、`components/`、`services/`、`data/` 等文件与目录。

（2）打开命令行终端（Windows 命令提示符 / PowerShell），切换到软件根目录。

（3）执行依赖安装命令：

```
npm install
```

系统将自动下载并安装软件所需的依赖包（React、Ant Design、Vite 等）。

### 2.3 启动与访问

（1）执行开发服务器启动命令：

```
npm run dev
```

（2）终端显示本地服务地址（默认 `http://localhost:5173`），在浏览器中访问该地址即可进入软件主界面。

（3）如需生成生产版本部署，可执行：

```
npm run build
```

构建产物生成于 `dist/` 目录，可部署至任意静态 Web 服务器或托管平台。

## 3. 软件使用说明

### 3.1 主界面与导航

软件主界面由顶部导航栏、中间内容区和（移动端）底部导航栏组成。

**【截图占位：软件主界面整体截图】**

顶部导航栏（桌面端）包含：

- **软件名称**：左上角显示"英语自学助手"标题；
- **功能导航**：智能学习、听读、单词、短语、复习、统计六个功能按钮；
- **番茄钟**：导航栏右侧显示番茄钟倒计时，可随时开始/暂停专注计时；
- **视图切换**：桌面端/移动端模式切换按钮；
- **设置入口**：齿轮图标，点击打开系统设置面板。

移动端模式下，顶部仅保留软件图标与番茄钟、设置按钮，功能导航移至屏幕底部，采用五个图标按钮（学习、听读、词库、短语、复习），统计功能入口位于"学习"完成页或顶部导航（移动端需先切换）。

### 3.2 单词学习模块

单词学习模块用于浏览与学习内置词库中的单词，点击顶部导航"单词"进入。

**【截图占位：单词学习主界面截图】**

#### 3.2.1 分类筛选

界面左侧（移动端为顶部横向滚动条）展示分类列表：全部、日常生活、人物相关、基础知识、居家物品、日常沟通常用短句、旅行沟通常用短句、工作沟通常用短句、生词练习。

- 点击任意分类，仅显示该分类下的单词；
- 点击"生词练习"，自动过滤掉已学过的单词，仅显示尚未学习的生词；
- 点击"全部"显示全部单词。

#### 3.2.2 浏览模式

- **顺序模式**：按词库原始顺序展示单词；
- **随机模式**：点击"随机模式"按钮切换，单词顺序随机打乱；点击右侧刷新图标可重新洗牌。

#### 3.2.3 发音与释义

- **点击单词卡片**：朗读该单词英文发音，同时自动标记该词为"已学习"；
- **点击卡片右侧喇叭图标**：慢速逐词播放（适用于多词短语，间隔时间可通过顶部滑杆 0-2000ms 调节）；
- **点击卡片下方释义区**：显示/隐藏中文释义；点击"隐藏中文/显示中文"按钮可一键控制所有卡片释义的显示状态。

#### 3.2.4 搜索

顶部搜索框支持输入英文单词或中文释义进行模糊搜索。搜索采用智能相关度排序：英文精确匹配优先，其次为单词边界匹配、前缀匹配、部分匹配，中文释义按匹配比例排序，句子类内容自动置后。

#### 3.2.5 分页与加载更多

- 每页显示数量可通过"每页"下拉框选择 20 / 50 / 100 个；
- 翻页通过左右箭头按钮操作，显示当前页/总页数及总单词数；
- 页面底部"加载更多单词"按钮可向下追加一页内容，无需翻页连续浏览。

### 3.3 短语跟读模块

短语跟读模块提供 2.7 万余条常用短句的浏览、跟读与循环播放功能，点击顶部导航"短语"进入。

**【截图占位：短语跟读主界面截图】**

#### 3.3.1 短语列表与难度筛选

- 短语卡片展示英文句子、中文释义、场景标签（如"At a restaurant"）与难度标识；
- 顶部难度筛选支持：全部、短句（1-3 词）、中句（4-6 词）、长句（7 词以上）；
- 点击"随机模式"按钮可将短语列表随机排序。

#### 3.3.2 单句操作

- **点击喇叭图标**：朗读当前短语；
- **点击短语卡片**：展开/收起该短语的详细内容（含上下文场景描述）；
- **点击句中任意单词**：弹出该单词的中文释义浮窗（自动进行词形还原处理，如"playing"→"play"、"dogs"→"dog"），移动端点击单词将自动发音并显示释义；
- **点击星形图标**：将短语加入收藏；
- **点击对勾图标**：将短语标记为"已掌握"。

#### 3.3.3 连续跟读播放

点击列表顶部"开始播放"按钮进入连续跟读模式，软件将按设定的范围与模式循环播放短语。

播放设置说明：

- **播放范围**：当前页 / 已加载 / 全部 / 收藏，四选一；
- **播放模式**：
  - 英文循环：反复播放英文原句；
  - 英-中-英：播放英文→中文→英文，便于理解记忆；
  - 中-英：先中文后英文；
  - 仅英文：只播放英文；
- **重复次数**：每条短语重复播放次数（可调）；
- **播放间隔**：两条短语之间的停顿时间（毫秒）。

播放过程中，当前正在播放的短语高亮显示并自动滚动至可视区域；点击"暂停/继续"按钮可随时控制播放状态。

#### 3.3.4 收藏夹练习

选择播放范围"收藏"或筛选收藏短语后，可对收藏的短语进行专项浏览与跟读练习。已掌握的短语在"全部"视图中显示绿色对勾标识。

### 3.4 智能学习模块

智能学习模块根据间隔重复算法自动生成学习计划，点击顶部导航"智能学习"进入。模块包含"选择题"与"听力拼句"两种学习模式，通过顶部按钮切换。

**【截图占位：智能学习-选择题模式界面截图】**

#### 3.4.1 选择题模式

（1）进入模块后，软件自动生成一组学习任务：

- 优先纳入**到期需复习**的单词（间隔重复算法判定）；
- 不足部分从**新单词**中随机补充；
- 每组数量默认为 10 个，可在顶部"每组"下拉框调整为 5 / 10 / 20 / 30。

（2）每题展示英文单词（自动发音），下方提供 4 个中文释义选项（1 个正确 + 3 个干扰项），选择正确答案后：

- 自动播放发音并进入下一题；
- 答错时错误选项被标记，可继续尝试直至答对；
- 软件根据错误次数评估记忆质量（无错误=质量5，有错误=质量2），并据此更新该单词的间隔重复参数。

（3）答题辅助功能：

- **提示按钮（H 键）**：随机排除 2 个错误选项，每道题仅可使用一次；
- **空格键**：重新朗读当前单词；
- **数字键 1-4**：快速选择对应选项。

（4）一组完成后显示完成界面，可点击"继续"生成新一组，或点击"返回统计"查看学习统计。

#### 3.4.2 听力拼句模式

（1）点击"听力拼句"切换到该模式，软件从短句库中随机抽取一组句子（默认 10 句）。

（2）**难度筛选**：短句 / 中句 / 长句，支持多选，按句子的单词数量自动匹配难度。

（3）练习流程：

- 系统自动朗读目标英文句子；
- 屏幕下方显示打乱的单词块（包含原句单词与若干干扰词）；
- 用户按听到的顺序依次点击单词块拼成句子；
- 点击"播放"按钮可重新听原句（每句最多播放 3 次）；
- 点击"逐词播放"可慢速逐词朗读；
- 拼句过程中可"撤销"上一步或"清空"已选内容；
- 点击"检查"提交答案：正确则自动进入下一句；错误则给出提示，可修改后重试。

（4）快捷键：空格=播放、回车=检查、退格=撤销、C=清空、左右方向键=切换上一句/下一句。

（5）一组完成后显示完成界面，可"继续"练习或"返回统计"。

**【截图占位：智能学习-听力拼句模式界面截图】**

### 3.5 听力训练模块

听力训练模块用于批量听音训练，点击顶部导航"听读"进入。

**【截图占位：听力训练界面截图】**

#### 3.5.1 训练模式

- **随机模式**：从全部词库中随机抽取单词进行播放；
- **分类模式**：选择指定分类（如"日常生活"），仅播放该分类下的单词。

#### 3.5.2 播放设置

- **批次大小**：每批播放的单词数量；
- **重复次数**：每个单词重复播放的次数；
- **播放间隔**：单词之间的停顿时间（0 秒起，可调）；
- **播放策略**：专注（重点重复未掌握单词）、均衡（按顺序播放）、探索（快速浏览大量单词）三种策略可选。

#### 3.5.3 播放与显示

- 点击"开始播放"进入听音模式：自动按 英文发音→中文释义→英文发音 的顺序循环播放；
- 当前播放的单词卡片高亮显示，播放进度清晰可见；
- 点击单词卡片可随时查看/隐藏中文释义；
- 一批播放完成后可自动切换下一批（需开启"自动切换"开关），并支持设置**定时自动关闭**（5/10/15/30/60 分钟后自动停止，适合睡前磨耳朵场景）。

### 3.6 游戏复习模块

游戏复习模块以"连连看"配对游戏形式巩固单词记忆，点击顶部导航"复习"进入。

**【截图占位：游戏复习界面截图】**

#### 3.6.1 游戏规则

- 每局随机抽取 8 个单词，左侧显示英文，右侧显示中文（顺序均已打乱）；
- 点击左侧英文，再点击右侧对应的中文释义进行配对；
- 配对正确：两个卡片变绿并绘制连线，得分 +10；
- 配对错误：卡片红色抖动提示，重新选择；
- 点击英文卡片时自动朗读发音，辅助记忆。

#### 3.6.2 通关与重开

- 全部 8 个单词配对成功后显示"全部通关"界面并展示得分；
- 点击"再玩一次"开始新一局，点击"重新开始"可随时重置当前局。

### 3.7 学习统计模块

学习统计模块展示用户的学习数据与成就，点击顶部导航"统计"进入（智能学习完成页也可跳转至此）。

**【截图占位：学习统计界面截图】**

#### 3.7.1 核心数据

统计面板以卡片形式展示四项核心数据：

- **连续打卡**：连续学习天数（中断一天后重新累计）；
- **已掌握**：通过间隔重复算法判定为"已掌握"的单词数量；
- **累计时长**：累计学习分钟数（番茄钟计时与学习会话时长自动累加）；
- **今日学习**：今日学习次数。

#### 3.7.2 成就里程碑

软件内置四枚成就徽章，满足条件自动解锁：

| 成就 | 解锁条件 |
| --- | --- |
| 初出茅庐 | 完成第一次单词学习 |
| 持之以恒 | 连续学习 3 天 |
| 词汇达人 | 掌握 50 个单词 |
| 专注大师 | 累计学习 100 分钟 |

#### 3.7.3 学习建议

面板底部根据今日学习进度与艾宾浩斯遗忘曲线原理，动态生成当日复习建议（如"建议你今天再复习 10 个单词以达到最佳记忆效果"）。

### 3.8 番茄钟

番茄钟常驻于顶部导航栏，帮助用户保持学习专注。

**【截图占位：番茄钟组件截图】**

- 默认专注时长 25 分钟，点击**播放按钮**开始倒计时，点击**暂停按钮**暂停，点击**重置按钮**归零；
- 倒计时期间右上角图标红色脉冲提示"专注中"；
- 计时过程中自动累计学习时长（每 1 分钟记 1 分钟，计入统计面板"累计时长"）；
- 倒计时结束弹出提示"专注时间结束！休息一下吧"，并自动累计一次专注会话。

### 3.9 系统设置

点击导航栏右上角齿轮图标打开设置面板。

**【截图占位：设置面板截图】**

#### 3.9.1 外观显示

- **深色模式**：自动（跟随系统）/ 浅色 / 深色 三档切换；
- **字体大小**：滑杆调节，范围 80% - 120%，实时生效。

#### 3.9.2 语音设置

- **英文发音人**：下拉选择系统可用的英文语音（选择后自动试听"Hello, how do I sound?"）；
- **中文发音人**：下拉选择系统可用的中文语音（选择后自动试听"你好，这个声音怎么样？"）；
- **语速**：滑杆调节（0.5x - 1.5x）；
- **音量**：滑杆调节（0% - 100%）。

所有设置即时保存，重启软件后自动恢复。

## 4. 数据存储与隐私说明

（1）本软件的所有学习数据（单词学习进度、复习计划、收藏、统计、设置等）均存储在用户浏览器本地（localStorage），**不上传任何服务器**。

（2）语音合成使用浏览器本地或系统语音能力，若浏览器提供在线语音（如 Chrome 的 Google 语音），发音内容将发送至语音服务商以合成音频，除此之外软件本身不采集、不传输任何用户数据。

（3）清除浏览器缓存/站点数据将清空学习进度，请勿随意清理。如需保留数据，请使用同一浏览器访问。

## 5. 常见问题与故障处理

**Q1：单词点击后没有声音？**

检查系统音量与浏览器标签页是否静音；确认浏览器支持 Web Speech API（Chrome、Edge 支持最佳）；可在设置中更换发音人或调大音量。

**Q2：可选发音人很少？**

语音列表由操作系统/浏览器提供。Windows 系统可在"设置-时间和语言-语音"中安装更多语音包；Chrome 登录 Google 账号后可使用在线语音。

**Q3：学习进度丢失？**

请确认未清除浏览器站点数据；不同浏览器之间的数据不互通。建议固定使用一个浏览器学习。

**Q4：移动端打开布局错乱？**

点击顶部视图切换按钮进入移动端模式，或直接使用手机浏览器访问；建议添加到主屏幕以 PWA 方式使用。

**Q5：如何更新软件？**

重新拉取源码包，执行 `npm install` 后重新 `npm run build` 构建部署即可。
